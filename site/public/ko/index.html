기능

먼저 가격, 그다음 지출.

001 / 공급자가 아닌 기능으로 호출

serp.google, x.search, keyword.volume, image.generate. 각 기능은 여러 공급자의 경로에 연결되며 필드 매핑과 배치 처리도 되어 있습니다.

002 / 모든 경로에 가격

로컬 캐시에서: 가격 API가 있는 공급자는 실시간 가격, 없으면 공개 가격표. 키가 없는 경로도 가격을 매겨 키를 하나 더 추가하면 얼마를 아낄지 보여 줍니다.

003 / 지출 직전 재견적

호출 직전에 가격을 새로 받습니다. AnyAPI는 가장 싼 소스로 고정하고 장애 전환을 끕니다.

004 / 넘지 않는 예산

매 실행을 먼저 견적하고 --max-usd를 넘으면 거부합니다. 기본 한도는 0.1달러입니다.

005 / 402에서 멈춤

402에서는 종료 코드 2, 첫 실패에서 멈춥니다. 에이전트는 이를 재시도가 아닌 중지로 읽습니다.

006 / 가격 기준선

최저가가 갑자기 오르면 새 가격을 승인할 때까지 실행을 멈춥니다.

007 / 중복 제거와 배치

입력은 중복을 제거하고, 공급자가 허용하면 쿼리 목록을 한 번의 배치로 실행합니다.

008 / 모든 호출을 장부에

응답을 저장하고 비용을 ~/.getcheapapi에 기록합니다. getcheapapi spend가 공급자와 엔드포인트별로 합산합니다.

009 / 미디어도

Yir를 통한 이미지·동영상·음성 생성도 작업마다 견적하고 서버 측에서 상한을 둡니다.

010 / 에이전트용 스킬

폴더를 Claude Code, Codex 등 에이전트에 연결하세요. 클론에서는 패키지 설치 없이 실행됩니다.

15개 기능, 5개 공급자, 명령 하나.

경로는 카탈로그 파일 하나에 있습니다. 가격과 엔드포인트는 바뀌므로 추가나 수정은 Pull Request로 합니다.

설치하기 전에

Q.001 / 무료인가요?

네. MIT 라이선스로 계정도 비용도 없습니다. 공급자에게 내 키로 직접 결제합니다.

Q.002 / 공급자마다 키가 필요한가요?

아니요, 하나면 충분합니다. 키가 없는 경로도 가격을 매기므로 키를 추가하면 얼마를 아낄지 볼 수 있습니다.

Q.003 / 데이터가 귀사 서버를 거치나요?

아니요. 가격 캐시, 장부, 저장된 결과는 모두 내 컴퓨터의 ~/.getcheapapi에 있습니다. 네트워크 트래픽은 API 호출 자체뿐입니다.

Q.004 / 가격은 얼마나 최신인가요?

가격 API가 있는 공급자는 실시간, 없는 곳은 공개 가격표입니다. 매 실행은 지출 직전에 다시 견적합니다.

Q.005 / LLM 호출도 라우팅하나요?

아니요. 텍스트 모델은 LiteLLM과 OpenRouter가 다룹니다. getcheapapi는 유료 데이터·미디어 API 전용입니다.

Q.006 / 공급자를 추가하거나 가격을 고치려면?

카탈로그 파일을 수정하고, 실제 공급자를 대상으로 무료 스키마 검사를 실행한 뒤 Pull Request를 보내세요.
