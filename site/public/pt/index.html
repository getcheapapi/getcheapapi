O que faz

Primeiro o preço. Depois o gasto.

001 / Peça um recurso, não um provedor

serp.google, x.search, keyword.volume, image.generate. Cada um aponta para rotas em vários provedores, com mapeamento de campos e lotes já resolvidos.

002 / Toda rota com preço

De um cache local: APIs de preço ao vivo onde existem, tabelas publicadas onde não. Rotas sem chave também são cotadas, então você vê quanto outra chave economizaria.

003 / Recota antes de gastar

Preços atualizados logo antes da chamada. O AnyAPI fica preso à fonte mais barata, com failover desligado.

004 / Um orçamento que não passa

Toda execução é estimada antes e recusada acima de --max-usd. O limite padrão é dez centavos de dólar.

005 / Para no 402

Código de saída 2 num 402, e parada na primeira falha. Um agente entende isso como parar, não tentar de novo.

006 / Preço de referência

Quando o preço mais barato dispara, a execução para até você aceitar o novo preço.

007 / Sem duplicatas e em lote

As entradas são deduplicadas, e uma lista de consultas roda num único lote quando o provedor permite.

008 / Toda chamada no livro-caixa

Respostas são salvas e cobranças registradas em ~/.getcheapapi. getcheapapi spend soma por provedor e endpoint.

009 / Mídia também

Geração de imagem, vídeo e voz via Yir, cotada antes de cada tarefa e com teto no servidor.

010 / Um skill para agentes

Ligue a pasta ao Claude Code, Codex ou outro agente. A partir de um clone, roda sem instalar o pacote.

15 recursos. 5 provedores. Um comando.

As rotas ficam num único arquivo de catálogo. Preços e endpoints mudam, então uma rota é adicionada ou corrigida por pull request.

Antes de instalar

Q.001 / É grátis?

Sim. Licença MIT, sem conta e sem taxa. Você paga os provedores diretamente com suas próprias chaves.

Q.002 / Preciso de uma chave por provedor?

Não. Uma basta. Rotas sem chave também são cotadas, então você vê quanto adicionar uma economizaria.

Q.003 / Meus dados passam pelos seus servidores?

Não. O cache de preços, o livro-caixa e os resultados salvos ficam em ~/.getcheapapi na sua máquina. O único tráfego são as próprias chamadas de API.

Q.004 / Quão atualizados são os preços?

Ao vivo onde o provedor tem API de preços, tabelas publicadas onde não tem. Toda execução recota logo antes de gastar.

Q.005 / Ele roteia chamadas de LLM?

Não. LiteLLM e OpenRouter cuidam dos modelos de texto. O getcheapapi é para APIs pagas de dados e mídia.

Q.006 / Como adiciono um provedor ou corrijo um preço?

Edite o arquivo de catálogo, rode a verificação gratuita de schema contra o provedor real e abra um pull request.
