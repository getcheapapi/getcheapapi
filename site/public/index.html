What it does

Prices first. Spends second.

001 / Ask for a capability, not a provider

serp.google, x.search, keyword.volume, image.generate. Each maps to routes across providers, with field mapping and batching done for you.

002 / Every route priced

From a local cache: live price APIs where providers have them, published tables where they do not. Routes you hold no key for are priced too, so you see what another key would save.

003 / Re-priced before it spends

Fresh prices right before the call. AnyAPI is pinned to its cheapest source with failover off.

004 / A budget it won't cross

Every run is estimated first and refused past --max-usd. The default cap is ten cents.

005 / Stops on 402

Exit code 2 on a 402, and a stop on the first failure. An agent reads that as stop, not retry.

006 / Price baseline

When the cheapest price jumps, the run stops until you accept the new price.

007 / Deduped and batched

Inputs are deduped, and a list of queries runs as one batch where the provider allows it.

008 / Every call on a ledger

Responses are saved and charges logged in ~/.getcheapapi. getcheapapi spend sums them by provider and endpoint.

009 / Media too

Image, video and speech generation via Yir, quoted before every job and capped server-side.

010 / A skill for agents

Link the folder into Claude Code, Codex or another agent. From a clone it runs without installing the package.

Before you install

Q.001 / Is it free?

Yes. MIT licensed, no account and no fee. You pay providers directly with your own keys.

Q.002 / Do I need a key for every provider?

No. One key is enough. Routes you have no key for are still priced, so you can see what adding one would save.

Q.003 / Does my data go through your servers?

No. The price cache, ledger and saved results live in ~/.getcheapapi on your machine. The only traffic is the API calls themselves.

Q.004 / How fresh are the prices?

Live where a provider has a price API, published tables where it does not. Every run re-prices right before it spends.

Q.005 / Does it route LLM calls?

No. LiteLLM and OpenRouter cover text models. getcheapapi is for paid data and media APIs.

Q.006 / How do I add a provider or fix a price?

Edit the catalog file, run the free schema check against the live provider, and open a pull request.
