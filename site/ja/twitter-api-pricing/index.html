用途別：どのAPIを使うか

投稿・いいね・DM、自分のアカウントのデータ
公式 X API。サードパーティの読み取りAPIは書き込みができず、自分のデータの読み取りは1件0.001ドルです。
キーワード検索・エゴサーチ・競合の監視
AnyAPI の twitter.search を最安のソースに固定。1件あたり twitterapi.io の約5.6分の1です。
プロフィール・フォロワー・IDでの投稿取得
twitterapi.io。プロフィールは100件以上まとめて取得すると1件1クレジットで、公式の1件0.010ドルより大幅に安くなります。
結果が空になりやすい検索
最低料金に注意。twitterapi.io は空の結果でも15クレジットかかり、公式は取得した投稿の件数で課金されます。

twitterapi.io と AnyAPI はXが運営・公認するサービスではなく、Xの規約はAPI以外でのデータ収集を制限しています。用途に照らして両方の規約を確認してください。SERP（検索結果）APIの料金は SERP API pricing（英語） で比較しています。

X API 料金のよくある質問

Q.001 / X APIは無料で使えますか？

新規の開発者は無料では使えません。2026年2月6日から従量課金が標準になり、新規登録に無料枠はありません。初回のクレジット購入後に20ドル分のクレジットがもらえます。

Q.002 / X APIの料金はいくらですか？

他人の投稿の読み取りが1件0.005ドル（約0.8円）、ユーザー情報の読み取りが1件0.010ドル、投稿が1件0.015ドル、URL付きの投稿が1件0.200ドルです。月額の基本料はありません。

Q.003 / X APIの料金は値上げされましたか？

2026年4月の改定で、URL付き投稿が1件0.200ドルになりました。URLなしの投稿は0.015ドルのままです。読み取りの単価は0.005ドルです。

Q.004 / 自動投稿すると月いくらかかりますか？

1日1本、URLなしなら月0.45ドル（約71円）、すべてURL付きなら月6.00ドル（約950円）です。投稿はサードパーティAPIではできないため、公式APIの料金になります。

Q.005 / 読み取り件数に上限はありますか？

従量課金では、投稿の読み取りは請求月あたり300万件が上限です。それ以上はEnterpriseプランが必要です。開発者コンソールで請求月ごとの支出上限も設定できます。

Q.006 / サードパーティのX APIは使っても大丈夫ですか？

twitterapi.io や AnyAPI はXが運営・公認するサービスではなく、Xの規約はAPI以外でのデータ収集を制限しています。用途に照らして、両方の規約を確認してください。

Q.007 / 一番安くキーワード検索する方法は？

2026年11月時点の価格では、AnyAPI の twitter.search を最安のソースに固定するのが最安で、約20件のページが0.00054ドル、1,000件で約0.027ドル（約4円）です。最も高いソースは28倍なので、フェイルオーバーは切ってください。

Q.008 / 料金の出典は？

Xの開発者向け料金ページ、twitterapi.io の料金ページ、AnyAPI のソース別ライブ価格APIで、2026年11月2日に確認しました。円は1ドル＝158円の概算です。getcheapapi quote x.search で自分のクエリの価格を無料で確認できます。
