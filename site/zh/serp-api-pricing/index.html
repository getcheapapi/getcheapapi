SERP API 账单会在哪里变贵

一次要 100 条结果
Google 在 2025 年 9 月停止了每页 100 条结果，所以大多数 API 把 100 条结果按 10 次搜索计费。
搜索运算符
DataForSEO 每用一个 site: 或 intitle: 这类运算符，价格就乘以 5。
用实时而不是队列
DataForSEO 实时模式是标准队列的 3.3 倍。结果能等几分钟的话，就用队列。
悄悄切换来源
AnyAPI 默认会在便宜来源失败后改用更贵的来源重试，Google 搜索最多贵到 4 倍，X（Twitter）API 搜索最多 28 倍。把来源固定住，并关掉自动切换。
用不完的套餐
SerpApi 的套餐不管你用了 10% 还是 100%，收费都一样；预付额度只按实际用量扣，直到过期为止。

SERP API 价格常见问题

Q.001 / 最便宜的 SERP API 是哪家？

按 2026 年 11 月 2 日核对的公开价格，最便宜的是 Searlo 的网页搜索档，$0.30 / 1,000 次；其次是 AnyAPI 最便宜的 Google 来源 $0.50，以及 DataForSEO 标准队列 $0.60。Serper 买最大的套餐包也能降到 $0.30 / 1,000 次。哪家对你最便宜，要看用量、速度要求和你需要的结果字段。

Q.002 / SerpApi 多少钱？

月付套餐从 $25 买 1,000 次（$25 / 1,000 次）到 $3,750 买 100 万次（$3.75 / 1,000 次），另有每月 250 次的免费套餐。失败、出错和命中缓存的搜索不计次；当月没用完的次数不结转。

Q.003 / 有免费的 SERP API 吗？

有免费额度，没有免费 API：SerpApi 每月 250 次，Brave 每月 $5 额度，Serper 一次性送 2,500 次，Searlo 一次性送 3,000 次，DataForSEO 送 $1 试用额度。Google 自家的 Custom Search JSON API 已不再接受新客户。

Q.004 / Google 的 Custom Search JSON API 还能用吗？

新客户用不了。Google 表示，老客户可以用到 2027 年 1 月 1 日，在此之前要迁到别的方案。截止前的价格是每天前 100 次免费，之后 $5 / 1,000 次，每天最多 10,000 次。

Q.005 / 每次查询要 100 条结果，要花多少钱？

Google 从 2025 年 9 月起不再支持每页 100 条结果，之后大多数服务商把 100 条结果按 10 页计费。在 AnyAPI 上翻页拿 100 条约 $0.005，而它一次调用返回前 100 条的接口要 $0.024。

Q.006 / 这些价格从哪来？

来自各服务商自己的价格页，以及 AnyAPI 按来源实时报价的价格接口，核对于 2026 年 11 月 2 日。运行 getcheapapi quote serp.google，就能在各条路线上给你自己的查询报价，一分钱不花。服务商只按价格排序。

Q.007 / Bing Search API 还能用吗？

不能。微软已在 2025 年 8 月停用 Bing Search API。Bing 结果仍有第三方在卖：AnyAPI bing.search 为 $0.85 / 1,000 次，GoAnyAPI 为 $2.00。

Q.008 / SERP API 搜索失败也收费吗？

看服务商。SerpApi 不计失败、出错和命中缓存的搜索，GoAnyAPI 对失败或空结果的调用不收费。跑大批量之前，先查清每家的规则。
