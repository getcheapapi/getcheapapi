X API 价格常见问题

Q.001 / X API 免费吗？

对新开发者来说不免费。从 2026 年 2 月 6 日起，按量付费成了默认方式，新注册账号没有免费档。首次购买后，X 会送 $20 额度。

Q.002 / X API 每月要多少钱？

按量付费没有月费，按资源计费。每月读 300,000 条帖子，按每条 $0.005 算就是 $1,500。按量付费每月最多读 300 万条帖子，再多就得签 Enterprise 方案。

Q.003 / twitterapi.io 怎么收费？

每返回 1,000 条帖子 $0.15（每条 15 credits，$1 = 100,000 credits），每次调用最少扣 15 credits，哪怕一条也没返回。用户资料按 100 个以上一批查询时，每个 1 credit。

Q.004 / 第三方 Twitter API 能用吗？

它们不归 X 运营，也没有 X 的背书，而且 X 的条款限制在其 API 之外采集数据。请对照你的用途，把它们的条款和 X 的条款都读一遍；发帖、点赞、发私信这类操作只能走官方 API。

Q.005 / 按关键词搜索 X，最便宜的办法是什么？

按我们 2026 年 11 月核对的价格，是 AnyAPI 的 twitter.search 固定到最便宜的来源：每页约 20 条 $0.00054，折合每 1,000 条约 $0.027。它最贵的来源要贵 28 倍，所以记得关掉自动故障转移。

Q.006 / 这些价格从哪来？

来自 X 的开发者价格页、twitterapi.io 的价格页，以及 AnyAPI 按来源实时报价的价格 API，核对于 2026 年 11 月 2 日。运行 getcheapapi quote x.search 可以给你自己的查询报价，不花一分钱。路线只按价格排序。

Q.007 / 通过 API 在 X 上发帖要多少钱？

每条 $0.015，帖子里带 URL 则是 $0.200。点赞、关注、转帖和私信每次 $0.015。第三方读取 API 不能发帖。

Q.008 / 怎么拿到 X API key？

在 X 的 Developer Console 里创建应用并购买额度，之后读写操作都按资源从余额里扣费。新的付费账号首次购买后会获得 $20 额度。
